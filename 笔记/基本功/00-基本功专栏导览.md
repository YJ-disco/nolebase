# 基本功专栏导览

本专栏收录计算机基础里绕不开的几件事，按两条线组织：**数据在网络里怎么传输**，以及**到了本机之后内核怎么处理它**。两条线各是一个子专栏，本目录不再放本级正文。

## 目录

**子专栏**：

- [[00-网络专栏导览|网络]] —— 十四个层次逐层展开：从应用层的 HTTP / TLS / RPC 往下走到传输层的 TCP 与 QUIC、网络层的 IP 与 ICMP，再到链路层与主机接入，最后落到 Linux 内核的收发包路径
- [[00-系统专栏导览|系统]] —— 操作系统内部机制：硬件与 CPU Cache、内核结构与设备管理、虚拟内存、进程线程与调度、进程间通信、多线程与并发、死锁与锁策略、文件系统与 I/O 栈、I/O 多路复用与 Reactor、Linux 性能观测

## 阅读顺序

两个子专栏各自成线，之间没有先后依赖，按需要选一条进：

- **网络**从 [[01-网络分层模型|网络分层模型]] 进入，编号即阅读顺序，逐层往下走到 Linux 内核的收发包路径。
- **系统**从 [[01-硬件结构与 CPU|硬件结构与 CPU]] 进入，同样是编号即阅读顺序：先硬件与内核，再到内存、进程、通信与并发，最后是文件系统、网络 I/O 与性能观测。

两条线的交界在**数据进出本机的一刻**：网络栏讲到内核收发包路径为止，系统栏接手讲数据到本机之后怎么被进程读写。
