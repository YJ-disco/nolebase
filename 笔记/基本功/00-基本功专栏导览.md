# 基本功专栏导览

本专栏收录计算机基础里绕不开的几件事：CPU 怎么切分时间、线程怎么并发、数据在内核与用户态之间怎么搬运、字节怎么在网络里传输、跨语言的调用链怎么追踪。

## 目录

- 01 · [[01-cpu时间分片|cpu时间分片]] —— 时间片切分、上下文切换的开销与调度公平性
- 02 · [[02-多线程与并发|多线程与并发]] —— 本库篇幅最长的一篇，覆盖并发的完整话题面
- 03 · [[03-浅谈零拷贝技术 mmap与sendfile|浅谈零拷贝技术 mmap与sendfile]] —— 传统 IO 的四次拷贝与四次切换、mmap、sendfile、DMA 的工作方式
- 04 · [[04-Python、C++ 与 GPU 软件栈工程基本功|Python、C++ 与 GPU 软件栈工程基本功]] —— 沿调用链跨层追踪问题：三层语言的分工、Python 性能陷阱、跨语言互操作契约
- 子专栏 · [[00-网络专栏导览|网络]] —— 十四个层次逐层展开：从应用层的 HTTP / TLS / RPC 往下走到传输层的 TCP 与 QUIC、网络层的 IP 与 ICMP，再到链路层与主机接入，最后落到 Linux 内核的收发包路径

## 阅读顺序

01 → 02 → 03 → 04。01 是 02 的前提：没有时间片切分就谈不上并发。03 与 04 各自独立，可以单独读。网络作为子专栏单独成线，编号即阅读顺序，从 [[01-网络分层模型|网络分层模型]] 进入后逐层往下。
