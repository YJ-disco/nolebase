# 系统专栏导览

这一栏收录操作系统的内部机制：CPU 怎么执行指令、内存怎么被虚拟化、进程与线程在内核里是什么、多个执行流怎么共享内存又怎么互相等待、文件怎么落到磁盘上、一次 I/O 要穿过哪些层，以及服务端怎么用一套线程处理海量连接。

| 不收 | 去哪看 | 本专栏只关心 |
| --- | --- | --- |
| 数据在网络上怎么传输、协议怎么握手 | `基本功/网络` | 数据到了本机之后，内核怎么处理它 |
| 具体编程语言与工具链的使用 | `语言/`、`AI/infra/` | 与语言无关的操作系统机制 |
| 数据库与中间件自己的锁、日志、缓存设计 | `中间件` | 操作系统给所有程序提供的那一层 |

## 阅读顺序

**01 → 02 → 03 → 04 → 05 → 06 → 07 → 08 → 09 → 10**。这条顺序是一条依赖链：先有硬件，才有内核，才有内核提供的各种抽象。

01 从最底层开始 —— 不懂 Cache 与缓存一致性，后面读「为什么上下文切换贵」「为什么伪共享致命」时就没有量级感。02 接在 01 之后，讲内核本身的结构与它怎么和硬件设备打交道，其中「一次 I/O 要穿过哪些层」是全栏的地基。03 与 04 是一组：内存管理与进程管理是内核的两大子系统，虚拟内存是进程地址空间的前提，而页表又与上下文切换的开销直接相关。**05 → 06 → 07 是并发这一侧的三段** —— 多个执行流要协作就得通信（05），要共享就得同步、同步用错就是死锁（06），而这两篇反复回指的那套同步原语的实现细节在 07（原子操作、内存序、内存屏障、伪共享）。08 换到存储这一侧，把 I/O 从文件系统一路铺到设备，并收进零拷贝的三条路径。09 是最上层的一次综合：把「一次 I/O 要穿过哪些层」与「怎么同时处理很多连接」合起来。10 收尾，把前面所有机制的观测入口收成一套可执行的排查剧本。
