# 区块链共识专栏导览

链场景下真正要回答的问题是「在什么信任模型与网络条件下，哪一类算法可用」，而不是「哪个算法最好」。本专栏按**网络形态**（公链 / 私链 / 联盟链）把主流共识算法摆在一张表里，逐条给出原理、特点、优缺点与典型应用。

## 目录

- 01 · [[01-区块链共识算法选型|区块链共识算法选型]] —— 公链的 PoW / PoS / DPoS，私链与联盟链的 PBFT / Raft / Paxos / PoA；末尾一张汇总表

## 阅读顺序

本专栏目前一篇，按公链 → 私链 → 联盟链的顺序读，最后看汇总表。

**与相邻目录的关系**：Raft 与 Paxos 在链场景里也会用到（例如 Hyperledger Fabric 的排序服务），但它们属于经典共识，算法本身的完整推导在 [[00-一致性共识算法专栏导览|一致性共识算法]]（该目录的 01–06 篇在建）。本专栏只讲它们在链里的用法。
