# 区块链共识专栏导览

链场景下真正要回答的问题是「在什么信任模型与网络条件下，哪一类算法可用」，而不是「哪个算法最好」。本专栏按**网络形态**（公链 / 私链 / 联盟链）把主流共识算法摆在一张表里，逐条给出原理、特点、优缺点与典型应用。

| 不收 | 去哪看 | 本专栏只关心 |
| --- | --- | --- |
| 一致性算法的完整推导（Paxos 的归纳证明、Raft 的选举安全性、PBFT 三阶段的来源） | [[00-一致性共识算法专栏导览\|一致性共识算法]] | 这些算法在链场景里被怎么用 |
| 分布式事务的提交协议（2PC / 3PC、TCC） | [[00-分布式事务专栏导览\|分布式事务]] | 链上「定序 + 执行」分离后由谁保证最终一致 |
| 具体链的产品、合约与钱包开发 | 各链官方文档 | 共识算法本身的机制、参数与选型判据 |

## 目录

## 阅读顺序

本专栏目前一篇，按公链 → 私链 → 联盟链的顺序读，最后看汇总表。

**与相邻目录的关系**：Raft 与 Paxos 在链场景里也会用到（例如 Hyperledger Fabric 的排序服务），但它们属于经典共识，算法本身的完整推导在 [[00-一致性共识算法专栏导览|一致性共识算法]]，本专栏只讲它们在链里的用法。
