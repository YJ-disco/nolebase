# 分布式专栏导览

本专栏收录分布式系统的基础理论：一致性的取舍、副本的组织方式、以及没有全局时钟时事件顺序怎么定义。具体的共识算法实现放在 `一致性共识算法/`。

- 02 · [[02-BASE 理论|BASE 理论]] —— 尚未编写
- 03 · [[03-一致性模型|一致性模型]] —— 线性一致性、顺序一致性、因果一致性、最终一致性，以及它们与 CAP 中 C/A 的对应
- 04 · [[04-一致性哈希算法|一致性哈希算法]] —— 哈希环、扩容缩容、数据倾斜与虚拟节点，含完整的 Java 实现

## 阅读顺序

阅读顺序覆盖整棵子树，子专栏按内容依赖穿插在本层笔记之间：

**01 → 02 → 03 → 时钟 → 04 → 一致性共识算法 → 分布式事务**

01 是理论总纲；03 建立在 01 之上，正文里两处直接引用 CAP 的 C 与 A。03 与 01 之间不宜插读其他内容。

**时钟接在 03 后面**：03 讲的因果一致性，技术定义正是 [[03-Lamport 逻辑时钟|Lamport 时钟]] 与 [[04-Vector 向量时钟|向量时钟]] 给的，两边互为前提。

**04 是分界线**：01 → 03 与时钟讲的都是「一致性的语义怎么定义」，04 起转到「数据与算法怎么组织」—— 数据怎么落到节点上，节点之间怎么达成一致，跨节点操作怎么保证原子（后两者见上面的子专栏）。
