# 分布式专栏导览

本专栏收录分布式系统的基础理论：一致性的取舍、副本的组织方式、以及没有全局时钟时事件顺序怎么定义。

本层是整棵子树的容器。四类专项各自成目录：**时钟**（时间怎么定义）、**一致性共识算法**（节点怎么达成一致）、**分布式事务**（跨节点操作怎么保证原子）、**区块链共识**（链场景下的共识选型）。另有四个目录已建、内容待补：**分布式存储**、**分布式计算**、**P2P 与路由**、**集群与运维**。

- 01 · [[01-CAP 定理|CAP 定理]] —— 三选二说法的实际含义、为什么 CA 不存在、PRO 与 PTO 原则、Quorum 的 W+R>N 配比；以及 Gilbert-Lynch 的形式化证明与 Brewer 十二年后的三点修正
- 02 · [[02-BASE 理论|BASE 理论]] —— 可用性是所需组件可用性的乘积（2PC 两个库的实例）、把组件从「必需」退成「可选」的手法、跨功能组与组内一致性的放松难度差异、四步 SQL 改写与幂等表
- 03 · [[03-一致性模型|一致性模型]] —— 线性一致性、顺序一致性、因果一致性、最终一致性，以及它们与 CAP 中 C/A 的对应

## 阅读顺序

阅读顺序覆盖整棵子树，子专栏按内容依赖穿插在本层笔记之间：

**01 → 02 → 03 → 时钟 → 04 → 一致性共识算法 → 分布式事务 → 区块链共识**

01 是理论总纲；03 建立在 01 之上，正文里两处直接引用 CAP 的 C 与 A。03 与 01 之间不宜插读其他内容。

**时钟接在 03 后面**：03 讲的因果一致性，技术定义正是 [[03-逻辑时钟：Lamport 与向量|Lamport 时钟]] 与 [[03-逻辑时钟：Lamport 与向量|向量时钟]] 给的，两边互为前提。

**04 是分界线**：01 → 03 与时钟讲的都是「一致性的语义怎么定义」，04 起转到「数据与算法怎么组织」—— 数据怎么落到节点上，节点之间怎么达成一致，跨节点操作怎么保证原子（后两者见上面的子专栏）。

**待建的四个目录排在最后**：它们讲的是用这些理论造出来的具体系统，读完理论再看实现，对照关系最清楚。四者内部按「存储 → 计算 → P2P 与路由 → 集群与运维」走 —— 存储与计算是主线，另两条是支线。
