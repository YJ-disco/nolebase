# AI Infra 专栏导览

本目录收**模型跑在真实硬件上**的那一层。它是 `AI/` 下的一棵子树，按「一条链 + 一篇横切」组织：

| 位置 | 收什么 | 篇数 |
| --- | --- | --- |
| [[00-GPU 与加速器专栏导览\|`gpu/`]] | 硬件本身 —— 架构、存储层次、算力与带宽、多卡互联拓扑 | 4 |
| [[00-CUDA 与算子优化专栏导览\|`cuda/`]] | 在硬件上写 kernel —— 编程模型、访存优化、经典算子 | 9 |
| [[00-训练专栏导览\|`train/`]] | 用多块硬件训练 —— 框架、切分策略、通信、显存账本 | 15 |
| [[00-推理优化专栏导览\|`infer/`]] | 把模型服务出去 —— 调度、显存管理、推理引擎、端侧 | 8 |
| [[01-数值计算与精度]] | **横切篇** —— 浮点格式、舍入、溢出下溢、混合精度与 Loss Scaling | 1 |

**前四块是一条链：硬件 → 在硬件上写算子 → 训练 → 服务。** 第五块不在链上 —— 它讲的是「**前面所有公式在有限精度下会怎么失真**」，被四块同时引用，所以放在这一层而不是任一子目录里。

它和 `AI/` 下另外两个目录的关系：

| 目录 | 关注什么 |
| --- | --- |
| `AI/ml/` | 机器学习算法与数学基础 |
| `AI/llm/` | 模型**本身** —— 架构、分词、位置编码、采样、缩放法则、幻觉 |
| `AI/agent/` | 模型**怎么被组织成应用** —— 循环、工具、协议、上下文、评测 |
| **`AI/infra/`** | 模型**怎么跑起来** —— 显存、调度、算子、训练、部署 |

边界不是绝对的，同一对象常在两个层次各有一篇。[[10-KV Cache 与推理优化]] 算的是 KV Cache 的**显存账本和注意力布局**（模型侧：为什么它这么大、怎么让它变小）；`infer/` 里的 [[02-PagedAttention：KV Cache 的分页管理]] 讲的是**引擎怎么把这块显存管起来**（infra 侧：块表、引用计数、抢占）。

## 材料边界

本目录的推理优化与分布式训练部分整理自外部教程 [AIInfraGuide](https://caomaolufei.github.io/AIInfraGuide/)（作者 caomaolufei，2026-09-21 抓取）。原文是完整教程，本目录**按概念颗粒度重新组织**，原文的章节大纲、页面目录与自测清单都不入正文；承重的量化断言逐条核对到一手来源（论文 / 官方文档与博客），核对结果与出处写在各篇 `## 参考`。

**源站有若干章只有大纲、没有正文**（已在源站侧确认，不是抓取遗漏）：推理侧的量化、Speculative Decoding、分布式推理、PD 解耦、性能分析与 Benchmark、生产部署与运维、选型；CUDA 侧的 AI 编译器、性能分析工具链。其中有可核实判据的部分已按主题并入各篇，其余进各子导览的待建清单。
